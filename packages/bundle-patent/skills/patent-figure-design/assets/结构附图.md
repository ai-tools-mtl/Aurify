# 结构附图绘制规范（结构示意图 / 剖视图 / 爆炸图）

配套 patent-figure-design 技能使用，管装置/机械/硬件类发明的结构类附图。走 diagram-design 的 SVG 管线：自包含 `.html`（内联 SVG）存 `figures/source/`（如 `图2-剖视.html`），渲染 PNG 落 figures/ 根；皮肤用 `cnipa-monochrome`（黑白、宋体、静态、无动画）。本文管的是该皮肤之上的结构制图纪律——核心原则（黑白极简、中文标注、图从文出、图内无图号图题）全部沿用，此处只写结构图特有的部分。

## 1. 视图类型与选用

| 视图 | 表达什么 | 何时用 |
|------|----------|--------|
| 总体结构图 | 整机外形与部件布局 | 通常为图1，最高层视角 |
| 剖视图 | 内部装配、腔体、隐藏结构 | 内部构造是发明点时 |
| 爆炸图 | 装配顺序、部件拆解关系 | 部件多、装配关系是发明点时 |
| 部件详图 | 单个关键部件的形状与接口 | 从属权利要求指向的改进点 |

总体结构图常用正交视图（主视/俯视/左视）；单一立体示意视图也可接受——结构附图是示意性表达，不追求投影严格性，但同一张图内视角要统一，不得一半正交一半立体混画。

## 2. 线型约定（四类，不得混用）

| 线型 | 线宽 | 用途 |
|------|------|------|
| 实线 | 1~1.2 | 可见轮廓、装配连接 |
| 虚线（`4,3`） | 1 | 隐藏轮廓、内部结构、运动极限位置 |
| 点划线（`8,3,2,3`） | 0.8 | 对称轴线、中心线、装配轴线 |
| 细实线 | 0.8 | 剖面线、引出线 |

- 剖切到的实体区域打 45° 均匀剖面线；**相邻零件的剖面线方向与间距至少错开一项、宜两项都错**——实测仅靠方向相反、间距相同（如都 8px）时，细线距下肉眼难以分辨，验收会反复误判；可靠做法是一个 45°/8px、相邻件 −45°/12px。
- 虚线只表达"看不见但存在"的轮廓——参考存疑、正文未披露的内部结构不打虚线，直接留白（见核心原则 5）。
- 同一张图内线宽只用本文列出的档位，与 cnipa-monochrome 的 `stroke-*` 档位一致。

## 3. 附图标记（结构图必带）

结构图与流程图最大的差别是必须带附图标记——代理人靠标记号在说明书与附图间交叉定位：

1. **标记用阿拉伯数字**（101、102…或 1、2…），全项目一套编号体系；同一部件跨图同一号，新增部件按序递增，不复用已废弃号码。
2. **标记加引出线**：细实线从部件引出，末端实心小圆点落在被标注部件的轮廓内，数字标记置于轮廓外空白处；指向同一部件多处出现时可重复标同一号。
3. **引出线纪律**：不交叉、不穿零件轮廓、不共用末端圆点；密集部件分侧引出，标记文字纵向对齐成列，不压零件轮廓。
4. **图文闭环**：说明书文字部分必须出现每个标记号且指代一致——交底书正文没写标记号时，提请用户补写或按正文部件名整理标记方案，不许只图有号、正文无号。
5. 跨图一致性终检时逐号核对：图内标记集合 = 说明书文字标记集合。

## 4. 爆炸图纪律

- **沿装配轴线拆解**：零件沿其装配方向平移分开，排布对应装配顺序，不散乱铺排。
- **只平移不旋转**：拆解后的零件保持原姿态；装配轴线用点划线贯通全图。
- **小件成组**：螺钉、垫圈等紧固件跟随其宿主部件成组放置，用细实线对齐装配位置。
- 拆解距离均匀，整图重心平衡；件数多时按功能分组、组间留更大间距。

## 5. 临摹与反虚构

- 用户供参考照片/草图/CAD 截图时，先 `read_image` 读图再动笔：临摹形状、相对位置、比例三类信息，不发明参考图中不存在的机构。
- 剖切内部结构无依据时（正文没写、参考图看不见）：改用外观视图，或用虚线示意轮廓，绝不虚构内部机构细节。
- 参考图与交底书正文冲突时以正文为准：先回头核对，改图或提请用户修订正文，不许硬画。
- 照片里的光影、颜色、背景、倒影一律丢弃；只保留轮廓、装配关系与比例。

## 6. 验收要点（叠加在通用检查单之上）

通用三级验收门照常执行（几何 lint 不适用 `.html` 源，绘制纪律与 subagent 视觉验收承担全部把关），结构图额外加验：

- [ ] 视图类型名副其实：剖视图就得真剖（剖面线 + 内部轮廓），不是外轮廓加几条虚线充数
- [ ] 每个部件带标记，引出线不交叉、不穿轮廓、末端圆点落在部件内
- [ ] 四类线型无混用；剖面区域已打剖面线，相邻零件剖面线错开
- [ ] 装配关系与交底书正文一致，无虚构部件（通用检查单「图从文出」项）
- [ ] 同一图内视角统一、比例协调；爆炸图沿轴线拆解、零件只平移不旋转
- [ ] 标记号集合与说明书文字标记号集合一致
