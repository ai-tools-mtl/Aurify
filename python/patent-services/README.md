# deepseek-harness-patent-services

English | [中文](README.zh.md)

MCP stdio server exposing the patent disclosure domain services to the dsh `patent` profile: template/reference parsing, whole-project export, application-set export, drawio figure rendering, archive search, docker-backed simulation experiments, and Chinese patent discovery. Mounted through [`@deepseek-ai/dsh-mcp-client`](../../packages/mcp/mcp-client/README.md), its tools reach the model as `mcp__patent__parse_disclosure_docx`, `mcp__patent__export_disclosure`, `mcp__patent__export_application_docs`, `mcp__patent__render_drawio_figure`, `mcp__patent__render_html_figure`, `mcp__patent__lint_drawio_figure`, `mcp__patent__search_patent_archive`, `mcp__patent__run_experiment`, and `mcp__patent__search_cn_patents`.

## Tools

- `parse_disclosure_docx(path, output_path?)` — parse one Word document into Markdown with the three-level numbering strategy (explicit heading styles, `第一章/一、/1.` at level one, `1.1/（一）` at level two, `1.1.1` at level three); optional Markdown output file. Tables and embedded images are skipped.
- `export_disclosure(project_dir, fmt)` — export on the bundled agency disclosure template (`assets/disclosure-template.docx`): the 专利申请技术交底书 header, the inventor table, and the page geometry ride along, the template's footer is blanked, the chapters fill the template's sections (一、名称 through 八、附图) in its own typography, and figures/图N.png embed into the 附图 section with the 图N label and its 08-drawings caption below each image (楷体_GB2312 四号, 1.5 line spacing, two-character first-line indent) with a reading hierarchy on top — bold section headings, bold unindented `##` subheadings, `●` hanging-indent bullets, and `**bold**` spans kept as real bold; chapters outside the eight template sections append as extra numbered sections, and `brief.md` stays out; `docx` (default, via python-docx) or `pdf` (best-effort, via weasyprint — an environment without its GTK libraries fails loud with install guidance).
- `export_application_docs(project_dir, fmt)` — export the application document set (`application/{claims,description,abstract}.md`) in the submitted package's shape: one Word section per document — 说明书摘要, 权利要求书 (one paragraph per numbered claim, Markdown continuation lines fold in), 说明书 (opening with the centered invention name, bold unindented section headings) — each carrying its document-type label in a centered bottom-bordered header (黑体 四号, spacing copied verbatim), 宋体 四号 body (Latin in Times New Roman, 1.5 line spacing, two-character first-line indent, the `●` bullet and `**bold**` hierarchy as the disclosure export), 权利要求书 and 说明书 restarting page numbering, and no page numbers shown; `docx`/`pdf` behavior as the disclosure export.
- `render_drawio_figure(source, fmt)` — render one `.drawio` source to `png`/`pdf`/`svg`/`jpg`: a source under `figures/source/` lands in `figures/` (the root stays a final-images-only surface; sources live in `figures/source/`, intermediates in `figures/tmp/`), any other source renders beside itself. The CLI resolves from `DSH_DRAWIO_BIN`, then PATH (`draw.io`/`drawio`), then the per-user Windows install (an explicit `DSH_DRAWIO_BIN` is strict — a bad path fails rather than falling back); the fallback runs `DSH_DRAWIO_DOCKER_IMAGE` (default `q771103517/dsh-patent:latest`, the CJK-font overlay built from `assets/Dockerfile.drawio` and published to Docker Hub — a missing image auto-pulls; rebuild and re-push under the same tag when a plugin update changes the Dockerfile); no usable backend fails loud with install/build guidance. A geometry lint runs before any backend: an error-severity fault (a waypoint inside a box, a bend shared by edges) refuses the render with the fix list, warnings (missing anchors, shared corridors) append to the success line.
- `lint_drawio_figure(source)` — lint one `.drawio` source against the figure-design skill's drawing disciplines before any render: edges without explicit exit/entry anchors (the auto-router's uncontrolled bends), waypoints clipped inside the boxes they route around, bends shared by several edges (the overlapping-segment fault), and parallel runs sharing one corridor. Each finding names its fix; error-severity faults are exactly what `render_drawio_figure` refuses to render, so call this while drawing and fix the geometry at the source.
- `render_html_figure(source, fmt)` — rasterize one self-contained HTML figure (diagram-design output) to png/jpg beside it through the Edge/Chrome headless screenshot (`DSH_HTML_BROWSER` overrides the executable); a source under `figures/source/` lands in `figures/`.
- `search_patent_archive(query, archive_dir, limit)` — Chinese-aware full-text search (jieba segmentation + SQLite FTS5 BM25) over the Markdown corpus under an archive root (a workspace of past projects, or one project's `reference/`); `exports/` and tool directories are skipped. Hits return path, title, and a centered snippet.
- `search_cn_patents(query, limit?, since_year?)` — discover Chinese patents on Google Patents for prior-art and background research: the query is the core feature words in Chinese, hits come back one line each (publication number, title, assignee, priority date) restricted to CN publications, and a hit's abstract and claim 1 are read by web_fetching the statically rendered detail page (`patents.google.com/patent/<公开号>/zh`). The unauthenticated `/xhr/query` endpoint needs network access to patents.google.com (the system proxy is the usual route — urllib picks it up on Windows); unreachable networks, HTTP errors, and unrecognized payloads all fail loud with a remedy, never an empty result, because an invented hit is worse than a failed search.
- `run_experiment(project_dir, experiment, command?, timeout_seconds?)` — run one simulation experiment in the docker runner: the project mounts at `/workspace`, the working directory is `experiments/<experiment>/`, a `requirements.txt` there installs before the command, and the run's combined output tail returns to the model. The `command` accepts one `python`/`python3` invocation with plain arguments only (default `python run.py`) — no shell operators — because it runs through `sh -c` against a read-write mount of the whole project; a human can widen it by setting `DSH_EXPERIMENT_ALLOW_ANY_COMMAND=1`. Every invocation — success, failure, or timeout — appends a run record (time, image, command, exit code, output tail) to `experiments/<experiment>/results/run-log.md`, the ledger every number quoted into the disclosure points at. The image (`DSH_PATENT_EXPERIMENT_IMAGE`, default `q771103517/dsh-patent-experiment:latest`, built from `assets/Dockerfile.experiment` and published to Docker Hub — a missing image auto-pulls; rebuild and re-push under the same tag when the baked stack changes) ships numpy/scipy/pandas/matplotlib/openpyxl and CJK fonts, so matplotlib renders Chinese labels without per-script font setup; an absent docker CLI fails loud with Docker Desktop guidance.

## Optional settings

User preferences live in `$DSH_HOME/patent-services.yaml` (default `~/.dsh/`), not in `setx` variables: `experiment_allow_any_command`, `experiment_image`, `drawio_bin`, `drawio_docker_image`, `html_browser`. Edits apply on the next tool call, no restart; a same-named environment variable still wins, and a broken or missing file just means the code defaults.

## Running

```sh
uv run --project python/patent-services python -m patent_services   # stdio server
uv run --project python/patent-services pytest                      # tests
uv build                                                            # wheel + sdist into dist/
```

The wheel is the installable form: it ships the template and Dockerfile assets and a `patent-services` console script. The `patent` bundle mounts the client row with two opt-in gates, both off by default (disabled — visible in `dsh --profile patent --dump-config`, absent from the tool table): `DSH_PATENT_SERVICES` runs the installed package through `uvx --from deepseek-harness-patent-services patent-services`, while `DSH_PATENT_SERVICES_DIR` (this checkout's absolute path) runs the module straight from source.

## Known Limitations and Deferred Work

- **Tables and images are not parsed** — the parser walks paragraphs only; a template with tabular content loses it in the Markdown projection.
- **PDF export prefers Word COM on Windows** — weasyprint (needing system GTK) remains the non-Windows fallback; both paths keep the docx in `exports/` beside the pdf.
- **No filesystem policy** — an MCP stdio server runs in the host process's trust domain, outside the dsh fs sandbox; it sees the paths the model passes.
